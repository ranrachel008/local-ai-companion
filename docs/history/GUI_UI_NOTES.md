# 歷史 UI 說明（0.1.12，以下保留原始記錄）

這份 0.1.12 源碼保留已完成的 Windows 11 UI、通用名稱＋功能搜尋修補、
模型設定與安裝流程，並將大型內容卡片改為原生 ttk Frame 渲染。

本次 0.1.11 源碼修訂已移除 Awesome Selfhosted 搜尋接入、1,351 筆索引與專用安裝限制，聚焦既有本地 AI 方案搜尋。介面布局與渲染方式保持不變。

本次只交付修訂源碼，未重新建置 Windows EXE。此前程式包仍包含 Awesome，需使用本源碼重新建置後才會生效。

## 修改內容

- 淺灰側欄與背景、白色內容區、藍色主要操作。
- Segoe UI Variable Text／Segoe UI 字型與標題層級；未安裝時使用可用字型。
- 首頁整理搜尋框、分類提示與來源連結，內容可捲動。
- 搜尋結果保留左右分欄，增加選取邊框、滑鼠移入狀態及 Tab／Enter／空白鍵選取。
- 窄視窗自動收起側欄，說明文字隨面板寬度換行。
- 保留文字選取、複製、原文／譯文、語言切換與安裝審核入口。
- 使用標準函式庫和既有 Tkinter／ttk；沒有新增應用程式執行依賴。

這是 Windows 11 風格的 Tkinter 介面，不是移植為 WinUI；未加入 Mica、透明視窗或自訂系統標題列。
