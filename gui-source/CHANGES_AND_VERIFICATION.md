# Local AI Companion 0.1.9 歷史修改與驗證基準

> 此文件記錄 0.1.9 的歷史驗證結果，不代表 0.1.10 的建置或驗收報告。

## ROOT CAUSE

- 0.1.8 沿用的執行緒證據顯示：17.5 秒取樣中，程序使用 15.734 秒 CPU；其中 UI 執行緒 TID 1784 使用 15.672 秒，其他執行緒合計 0.062 秒。Python 堆疊位於 `app.py: main -> tkinter.mainloop`。
- 同一設定與首頁布局下，大型 `Card.TFrame` 的拉伸影像背景是目前唯一直接相關的渲染差異。既有定向比較中，簡化 Card 渲染後，UI 執行緒約使用 0.922–1.02 秒／5 秒，定向輸入分別約 0.168 秒與 0.317 秒。
- 使用者在 0.1.8 的實際操作仍是每次點擊至少等待五秒，因此 0.1.8 不視為已修復。
- 本工作階段的原生 Windows GUI 控制介面沒有列出可操作的桌面應用程式，無法完成指定的封裝版普通點擊、輸入與刪除 A/B；上述比較只能作為既有方向性證據，不能在本次把根因宣稱為完整驗證。

## CHANGES

- 將大型 `Card.TFrame` 改為原生 `ttk.Frame` 的白色平面背景，不再建立或拉伸影像背景；保留 Windows 11 配色、布局、字型、導航與按鈕。
- 介面標題、品牌文字、版本與建置檔名更新為 `Local AI Companion 0.1.9`。
- 保留既有使用者資料位置 `%LOCALAPPDATA%\Ornith-Solution-Scout`，未修改搜尋修補、模型設定、模型服務、安裝研究或安裝流程。
