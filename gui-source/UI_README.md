# Local AI Companion 0.1.17 使用說明

完整解壓程式包，保留 EXE 旁的 `_internal` 目錄，再雙擊
`Local-AI-Companion-0.1.17.exe` 開啟視窗。

搜尋方案、閱讀來源並整理安裝計畫後，可請雲端 AI 協助審閱，或自行核對。
只有你確認批准並執行後，程式才會開始已支援的安裝步驟。
目前的驗收範圍與限制見 [0.1.17 驗收記錄](../docs/ACCEPTANCE_0.1.17.md)。

## 開啟工作紀錄與切換語言

1. 在首頁按「工作紀錄」，選擇已保存的工作編號，再按「開啟已保存工作」。
   開啟只讀取原有紀錄，不會搜尋、研究、批准、續跑或安裝。
2. 紀錄缺失、損壞或來源綁定不符時，顯示既有還原失敗頁；不補造工作或結果。
3. 結果頁與生命週期頁可從語言選單切換六種語言。切換後仍停留同一工作頁，
   不返回首頁，也不重新執行安裝。

## 安裝審閱：雲端 AI 或人類自行確認

1. 選定方案、確認來源與安裝位置，完成原文安裝研究後，開啟安裝計畫。
2. 如果顯示需要審閱，可選擇「問雲端 AI」：開啟報告、複製內容，
   自行貼至 ChatGPT、Claude、Grok 或 Gemini。這個按鈕不會自動傳送或呼叫雲端。
   報告含來源、版本、環境位置、作者原始命令、可執行項與未解決項；
   貼上前自行檢查內容。請 AI 對照原文，指出適用條件、缺少前置需求與最小修正。
3. 也可以由人類自行確認：展開進階詳細內容，逐項對照作者說明、
   本機環境與未解決項。了解後才能選擇「按專案建議繼續」（簡體介面為「按项目建议继续」）。
   無法判斷時取消，補齊資料後再處理。雲端 AI 的意見也仍需要使用者確認。
4. 確認風險後，程式記錄此次選擇並批准既有計畫；在已批准頁面按下執行，
   才會開始已批准的固定安裝步驟。手動審閱項仍不會變成自動可執行步驟。
   改動計畫或來源需要重新審閱，不能用 AI 回覆代替原文來源或執行批准。
5. 查看結果頁：安裝成功、失敗或已停止，以及每一步的成功、失敗、停止、
   未執行狀態；有紀錄時顯示結果、退出碼、命令輸出與錯誤原因。
   命令執行失敗與來源校驗停止分開顯示。取消會保留已完成步驟，停止後續步驟。
   重新開啟已保存的工作紀錄時，會依保存的各步結果判斷總結果，不需重裝。
6. 需要繼續時使用原有「核准修正並繼續」或「繼續」流程。
   安裝成功只代表已批准步驟完成；登入、平台設定、系統工具或候選軟體完整功能，
   仍須按作者說明驗證，不能從安裝成功直接推定全部可用。
